守护进程操作

停用模块请到内核管理器里关闭本模块开关，supervisor 会自动还原限流。 恢复系统默认限流 会把 wired_chg_curr / ichg_limit 复位，仅在模块异常时手动使用。
当前为演示模式（未检测到 KernelSU / WebUI-X 环境），页面数据由本地模拟器生成，仅用于界面预览。
所有键值经 thermocharge set 白名单校验后写入 /data/adb/thermocharge/config.conf 并即时通知守护进程重载， 越界值会被二进制拒绝，不会静默生效。范围与 src/thermocharge.c 的键表一致。
恢复默认会把所有配置项写回模块通用默认值（目标 43℃、硬上限 45℃、 max_ma=20000、功率上限 0 W 自动不限等），不会自动套用机型参数； 要回到 K90 Ultra 档案请重新安装模块。 你手动调过的值都会被覆盖，没有逐项撤销。默认值由二进制的 thermocharge defaults --apply 写入，与 cfg_defaults() 同源，不会和代码里的默认值对不上。
